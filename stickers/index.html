Фото для портрета

JPEG, PNG, WebP или HEIC. До 38 МБ на весь заказ. Нужен только анфас. Оба поворота можно добавить по желанию.

Ваши реакции

Сначала вы посмотрите портрет. В пакет входят до трёх версий портрета и один круг правок по выбранным стикерам.

Фотографии сохраняются на сервере заказа и передаются в генератор изображений OpenAI для отрисовки. Ссылку на заказ сохраните для себя.

Укажите ник с @ или без неё либо ссылку t.me/username. По этому контакту мы сможем прислать ссылку на готовый набор.
