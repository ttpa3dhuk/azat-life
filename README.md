# azat.life

Личный сайт Азата Хусаенова — технический директор мероприятий.

Статика без сборки: `index.html` + `css/style.css`. Хостинг — GitHub Pages, домен `azat.life` (файл `CNAME`).

## Локальный просмотр

Открыть `index.html` в браузере — этого достаточно, сборки нет.

## Деплой

Репозиторий: <https://github.com/ttpa3dhuk/azat-life>. Pages собирается из ветки `main`,
корень репозитория. Публикация — обычный `git push`, отдельной сборки нет.

Домен `azat.life` зарегистрирован на reg.ru, зону обслуживают `ns1/ns2.hosting.reg.ru` —
значит записи правятся в панели reg.ru. Нужны четыре A-записи на apex:

    185.199.108.153   185.199.109.153   185.199.110.153   185.199.111.153

плюс CNAME `www` → `ttpa3dhuk.github.io`. Старую A-запись на хостинг reg.ru
(`31.31.196.17`) убрать, иначе домен продолжит показывать заглушку.

Файл `CNAME` в репозитории обязателен: по нему GitHub понимает, какой из сайтов
на этих общих IP отдавать для запроса `azat.life`. Удалять нельзя.

После того как DNS разойдётся, в Settings → Pages включить Enforce HTTPS
(сертификат Let's Encrypt выпускается автоматически, но только когда домен уже указывает на GitHub).

## Логотипы клиентов

`assets/logos/` — белый монохром на прозрачном фоне. Каждый файл лежит на холсте высотой
150 px и отцентрован внутри него, поэтому в CSS у всех одна `height: 44px` и они стоят
на общей линии. Размер внутри холста подобран на глаз: лок-апы «значок + подпись»
читаются мельче однострочных надписей той же высоты, поэтому у них он больше.
Выводятся с `opacity: .5`, при наведении — полная непрозрачность.

Источники: сайт ETS Production, Wikimedia Commons, официальные материалы брендов.

## Записи из Telegram

Блок «Пишу в Telegram» показывает три последние записи канала `@azatlife`.

Обновляется само: `.github/workflows/telegram.yml` дважды в день (09:00 и 21:00 МСК)
запускает `tools/fetch_posts.py`, тот читает публичную страницу `t.me/s/azatlife`
и кладёт записи в `assets/posts.json`. Если содержимое не изменилось — коммита нет.
Нужно прямо сейчас — Actions → «Свежие записи из Telegram» → Run workflow.

Почему так, а не виджетом: прямой запрос к t.me из браузера запрещён CORS,
а официального виджета «лента канала» у Telegram не существует — есть только
вставка одного конкретного поста по номеру.

Что стоит знать:

- Канал должен оставаться публичным, иначе страница `t.me/s/…` перестанет отдавать посты.
- Записи без текста (только фото или видео) пропускаются.
- Если `posts.json` недоступен или пуст, секция просто не показывается — вёрстка не ломается.
- GitHub отключает расписание после 60 дней без активности в репозитории; включается кнопкой в Actions.
